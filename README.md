# AIダイエットアシスタント — Phase 1 MVPプロトタイプ

いただいたBlueprintの「Phase 1」スコープを、ブラウザ単体で動く単一HTMLファイルとして
プロトタイプ化したものです。実装可否を判断しやすいよう、実際に触って動かせる形にしています。

## ファイル構成

- `index.html` … アプリ本体(このファイル1つだけで動作します)
- `README.md` … このファイル

ダブルクリックしてブラウザで開くか、スマホに転送してSafari/Chromeで開いてください。
iPhoneでは共有ボタン→「ホーム画面に追加」でアプリのように使えます。

## Phase 1 スコープとの対応

Blueprintに記載の「Phase 1(MVP)」項目は、この順で実装しています。

- ユーザー登録 → 初回起動時のオンボーディング(年齢・性別・身長・体重・目標体重・運動習慣・1日に使える時間・目標歩数)
- 体重記録・目標体重 → 「体重」タブ(推移グラフ・目標ライン付き)
- 歩数 → 「歩数」タブ(直近7日の棒グラフ・目標ライン付き)、および「今日」タブから当日分をクイック入力
- 食事記録・簡単なカロリー管理 → 「食事」タブ(カロリー・P/F/Cのメーター表示、手入力で記録)
- AIによる毎日のアドバイス → 「今日」タブの🤖カード。気分(疲れた/ふつう/元気)や当日のカロリー収支に応じてメッセージが変化
- 10〜15分のトレーニング提案 → 気分・1日に使える時間をもとに、その日のおすすめ運動(名称・時間・強度)を自動提示
- 「食べ過ぎても怒らないAI」 → 今日あったことを自由入力すると、キーワードとカロリー収支に応じて共感的な返信をするミニチャット欄

## 重要な制約(実装可否の判断材料)

- **「AI」はすべてルールベースの簡易ロジックです。** 本物のローカルAI/クラウドAIは呼び出していません。
  Blueprintにある「ローカルAI」「クラウドAI」の3層構造を実現するには、別途オンデバイスLLM(Core ML変換モデル等)
  やAI APIとの連携実装が必要です。今回はそのAIが返す”体験”だけを先に検証できるようにしています。
- **HealthKit連携はしていません。** ブラウザからは端末の歩数・運動データに直接アクセスできないため、
  歩数は手入力にしています。実機のiOSアプリ(Swift/SwiftUI)にする場合は、この部分をHealthKitのAPI呼び出しに
  置き換える形になります。
- **データは端末のブラウザ内(localStorage)にのみ保存されます。** 他の端末とは同期されず、ブラウザのデータを
  消去すると記録も消えます。複数端末対応やバックアップが必要な場合は、サーバー/DB側の実装が別途必要です。
- カロリー・PFC目標はMifflin-St Jeor式による概算です。医療的な正確性は保証されないため、実運用では
  管理栄養士等の監修や免責表示の強化が必要です(アプリ内にも簡易的な注意書きを表示しています)。
