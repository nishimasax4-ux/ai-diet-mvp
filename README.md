# トレーニングログ(スタンドアロン版)

Claudeを介さずに、ブラウザ単体で動くトレーニング・体重・食事の記録アプリです。
データは端末の localStorage に保存され、保存のたびに Google スプレッドシートへも自動で書き込まれます。
Claude の API は一切呼び出さないため、利用枠(usage)は消費しません。

## 今回の更新内容

- **記録の編集機能**: 各記録(筋トレ・有酸素・体重・食事)の✏️ボタンから内容を編集できるようになりました。編集画面から削除もできます。
- **履歴のカレンダー表示**: 「履歴」セクションに リスト / カレンダー の切り替えを追加。カレンダーの日付をタップするとその日の記録一覧が表示されます。
- **目標設定・達成率**: 「🎯 目標」カードで体重目標・週間トレーニング目標(回数)を編集可能に。現在の達成率をバーで表示します。
- **進捗グラフ**: 「📈 進捗」カードに、直近8週間のトレーニング頻度(目標ラインつき)と、種目を選んで確認できる重量推移グラフを追加しました。
- **部位ごとの種目選択肢**: 筋トレの「種目」欄に、選んだ部位(胸・背中・脚・肩・腕・腹筋)に応じたおすすめ種目のチップを追加しました。タップで入力欄に反映されるので、毎回手入力しなくても記録できます。もちろん自由入力もそのまま使えます。記録の編集画面でも同様に選べます。

## ファイル構成

- `index.html` … アプリ本体(このファイル1つだけで動作します)
- `apps-script.gs` … Googleスプレッドシートに書き込むための Google Apps Script コード
- `README.md` … このファイル

## セットアップ手順

### 1. 記録用のGoogleスプレッドシートを作る

1. [Google スプレッドシート](https://sheets.google.com) で新規シートを作成し、好きな名前を付ける(例:「トレーニングログ」)。
2. メニューから **拡張機能 → Apps Script** を開く。
3. デフォルトで入っているコードを全部消して、`apps-script.gs` の中身を貼り付けて保存する。
4. 画面右上の **デプロイ → 新しいデプロイ** をクリック。
5. 種類の選択で歯車アイコンから **ウェブアプリ** を選ぶ。
6. 設定:
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
7. **デプロイ** をクリックし、Googleアカウントでの承認を求められたら許可する。
8. 発行された **ウェブアプリのURL**(`https://script.google.com/macros/s/.../exec` の形式)をコピーしておく。

### 2. index.html にURLを設定する

`index.html` の冒頭付近にある以下の行を、手順1でコピーしたURLに書き換える。

```js
const GAS_URL = "PUT_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
```

### 3. ホスティングする(iPhoneのホーム画面に追加するため)

ローカルファイルのままだとiPhoneの「ホーム画面に追加」が安定しないため、どこかに公開してURLを持たせるのがおすすめです。手軽な方法をいくつか挙げます。

**GitHub Pages(無料・おすすめ)**
1. GitHubに新しいリポジトリを作る(例: `training-log`)。
2. このフォルダの `index.html` をリポジトリのルートに置いてpushする。
3. リポジトリの Settings → Pages で、公開元をそのブランチ(例: `main`)のルートに設定する。
4. 数分後、`https://<ユーザー名>.github.io/training-log/` のようなURLでアクセスできるようになる。

Claude Codeを使う場合、`git init` → `gh repo create` → `git push` → Pages設定、までを一通り自動化してもらうこともできます。

**Google Cloud Run**
すでにfreeeの自動化などでCloud Runを使っているなら、静的ファイル配信用のコンテナ(nginxなど)でこの `index.html` を配信することもできます。GitHub Pagesより一手間増えますが、他のインフラと管理を一本化したい場合はこちらでも構いません。

### 4. iPhoneのホーム画面に追加する

1. 公開したURLをiPhoneのSafariで開く。
2. 共有ボタン(□に↑のアイコン)をタップ。
3. 「ホーム画面に追加」を選択。

これでアイコンをタップするだけでフルスクリーンのアプリのように起動します。

## 動作の仕組み

- 記録の追加・削除のたびに、まず端末の localStorage に即座に保存します(ネット接続不要)。
- その直後にバックグラウンドで Apps Script の Web アプリ URL に記録全体を送信し、スプレッドシートの内容を丸ごと上書きします。
- 通信に失敗しても localStorage 側のデータは失われません。画面上部の同期ステータスをタップすると再試行できます。

## 既知の制限・カスタマイズ余地

- 現状、複数端末間でのデータ共有は「都度スプレッドシートに書き込む」一方向のみです(スプレッドシート側からアプリへの読み込みは未実装)。複数端末で使いたい場合は、起動時にスプレッドシートからデータを読み込む処理を追加すると良いです。
- ホーム画面用のアイコン画像(`apple-touch-icon`)は未設定です。好みの画像を用意して `<link rel="apple-touch-icon" href="icon.png">` をheadに追加すると、アイコンが見た目良くなります。
- デザイン(色・フォント)は元のReact版アーティファクトと同じトーンに合わせています。調整したい場合は `<style>` 内のCSS変数(`--rust`, `--steel`, `--moss` など)を変更してください。
